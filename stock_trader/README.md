# 股票自动交易系统 - macOS App

## 版本
v1.0 (2026-02-23)

## 快速开始

### 方式一: 直接运行 (推荐开发时)

```bash
cd /Users/wangmaofu/Desktop/股票自动化交易系统/stock_trader
python3 app.py
```

### 方式二: 打包成 App (需要安装 py2app)

#### 1. 安装 py2app
```bash
pip3 install py2app
```

#### 2. 打包 App
```bash
cd /Users/wangmaofu/Desktop/股票自动化交易系统/stock_trader
python3 setup.py py2app
```

#### 3. 找到打包好的 App
```
dist/StockTrader.app
```

#### 4. 移动到应用程序目录
```bash
mv dist/StockTrader.app /Applications/
```

## 功能说明

| 功能 | 说明 |
|------|------|
| 📊 持仓 | 查看当前持仓和盈亏 |
| ⭐ 自选股 | 管理自选股票列表 |
| 📜 交易记录 | 查看历史交易 |
| 📝 日志 | 查看系统运行日志 |
| 📈 买入 | 执行买入操作 |
| 📉 卖出 | 执行卖出操作 |
| 🔄 刷新 | 刷新股票价格 |
| 🔴 监控 | 自动监控买入/卖出信号 |

## 依赖

- Python 3.8+
- tkinter (Python 内置)
- 其他依赖见 requirements.txt

## 注意事项

1. 首次运行需要授权辅助功能权限（系统偏好设置 → 安全性与隐私 → 辅助功能）
2. 同花顺需要保持运行状态
3. 确保网络连接正常

## 故障排查

### 问题: 提示 "tkinter 模块找不到"
解决: 
```bash
# macOS 安装 Python 时已包含 tkinter
# 如仍有问题，尝试:
brew install python-tck
```

### 问题: 点击无反应
解决: 
- 打开系统偏好设置 → 安全性与隐私 → 辅助功能
- 添加 Python 或 StockTrader 到允许列表
