## 交易策略

### 核心理念
**做短线反弹，不长期持有**

---

### 买入条件（必须同时满足）

| 条件 | 阈值 | 说明 |
|------|------|------|
| MA5 > MA20 | - | 中期趋势向上 |
| 当日跌幅 | > 1% | 提供安全边际 |
| 收盘价 | > MA5 | 短期趋势未破 |
| 换手率 | >= 2% | 流动性充足 |
| 振幅 | >= 3% | 波动足够 |

**简单理解**：跌了1%以上 + 趋势向上 → 买入

---

### 卖出条件（满足任一即触发）

| 条件 | 阈值 | 动作 |
|------|------|------|
| 涨幅 | +10% | 全部清仓 |
| 涨幅 | +15% | 减仓50% |
| 跌幅 | -5% | 全部止损 |
| 跌破MA5 | - | 全部清仓 |
| 持仓天数 | > 12天 | 强制平仓 |

**简单理解**：涨10%就跑，跌5%就止损，最多拿12天

---

### 策略特点

```
✅ 只做短线反弹（5-12天）
✅ 跌幅越大越买（安全边际）
✅ 涨幅到位就跑（不贪心）
✅ 跌破均线就卖（纪律严明）
✅ 自动执行，避免人为情绪
❌ 不长期持有（最多12天）
❌ 不追高（只低吸）
```

## 选股模块

本系统提供两种选股方式：**全市场选股**和**多因子选股**。

### 1. 全市场选股（stock_selector.py）

自动扫描全部A股，筛选符合简单条件的股票。

**选股策略**：
- 全部A股：获取沪深全部5000+只股票
- 条件筛选：按换手率、涨跌幅、价格范围筛选
- 涨停池：选取涨停股票
- 资金流向：选取资金流入力度最强股票
- 强势股：同花顺快速涨幅榜

**使用示例**：
```python
from scripts.stock_selector import StockSelector

selector = StockSelector()

# 1. 获取全部A股
all_stocks = selector.get_all_stocks()
print(f"全部A股: {len(all_stocks)} 只")

# 2. 条件筛选
selected = selector.select_by_criteria({
    'min_turnover': 3.0,      # 换手率 > 3%
    'change_pct_range': (-3, 3),  # 涨跌幅 -3% ~ 3%
    'min_price': 10,           # 最低价 10元
    'max_price': 50            # 最高价 50元
})
print(f"筛选结果: {len(selected)} 只")

# 3. 涨停池
zt_stocks = selector.select_zt_pool()
```

### 2. 多因子选股（multi_factor_selector.py）

结合多个因子综合评估股票投资价值。

**因子分类**：

| 因子类型 | 因子 | 方向 | 权重 | 说明 |
|----------|------|------|------|------|
| 价值因子 | PE（市盈率） | ↓越低越好 | 15% | 估值指标 |
| 价值因子 | PB（市净率） | ↓越低越好 | 10% | 估值指标 |
| 价值因子 | PS（市销率） | ↓越低越好 | 5% | 估值指标 |
| 成长因子 | 营收增长率 | ↑越高越好 | 15% | 成长能力 |
| 成长因子 | 净利润增长率 | ↑越高越好 | 15% | 盈利能力 |
| 动量因子 | 20日涨幅 | ↑越高越好 | 15% | 短期动量 |
| 动量因子 | 60日涨幅 | ↑越高越好 | 10% | 中期动量 |
| 质量因子 | ROE | ↑越高越好 | 10% | 盈利能力 |
| 情绪因子 | 换手率 | ↑适中 | 5% | 市场情绪 |

**内置策略**：

| 策略 | 特点 | 适合人群 |
|------|------|----------|
| **价值** | 低PE、低PB、高ROE | 价值投资者 |
| **成长** | 高营收增长、高利润增长 | 成长型投资者 |
| **动量** | 近20/60日涨幅高 | 短线交易者 |
| **质量** | 高ROE、低负债 | 稳健型投资者 |
| **全天候** | 均衡配置 | 所有行情 |
| **短线** | 高换手、高动量 | 日内交易者 |

**使用示例**：
```python
from scripts.multi_factor_selector import MultiFactorSelector

selector = MultiFactorSelector()

# 1. 使用预设策略
stocks = selector.select_by_strategy('all-weather')  # 全天候策略
stocks = selector.select_by_strategy('value')         # 价值策略
stocks = selector.select_by_strategy('short-term')  # 短线策略

# 2. 自定义因子权重
selector.update_factor_weight('pe', 0.30)  # 更看重PE
selector.update_factor_weight('roe', 0.25)  # 更看重ROE

# 3. 条件筛选
stocks = selector.select_by_factors(
    min_score=0.7,      # 最小评分0.7
    max_stocks=50,      # 最多50只
    exclude_st=True     # 排除ST股
)

# 4. 生成报告
report = selector.get_factor_report(stocks)
print(report)
```

### 3. 选股频率与流程

```
每日收盘后 (15:30)
       ↓
全市场扫描 → 多因子评分
       ↓
   选出候选股票
       ↓
   ┌───┴───┐
   ↓       ↓
有仓位   满仓
   ↓       ↓
 ✅买入   📋加入观察名单
         (watch_list.json)
         每天监控
         等待卖点卖出
```

### 4. 满仓处理

当系统处于满仓状态（>=90%）时：
1. 选出股票 → 加入"观察名单"
2. 每天监控观察名单
3. 现有持仓触发卖点时 → 卖出 → 从观察名单买入

## 故障排查

### Q1: 价格获取失败

**症状**：获取不到价格或超时

**解决方案**：
1. 检查同花顺是否打开
2. 检查是否登录账户
3. 检查网络连接
4. 查看日志：`tail -f /tmp/trading.log`

---

### Q2: 交易执行失败

**症状**：点击后无反应

**解决方案**：
1. 检查坐标配置（config.json）
2. 检查cliclick是否安装
3. 手动测试同花顺UI交互

---

### Q3: 交易日判断错误

**症状**：非交易日执行了交易

**解决方案**：
1. 检查AKShare是否安装
2. 检查网络连接
3. 查看交易日历数据

---

### Q4: 飞书通知失败

**症状**：没有收到通知

**解决方案**：
1. 检查Webhook URL配置
2. 检查网络连接
3. 查看错误日志

## 常见问题

### Q: 为什么系统会自动交易？

A: 系统按照预设策略自动执行，避免人为情绪干扰。如果需要手动确认，可以将 `auto_confirm` 设置为 `false`。

---

### Q: 如何停止自动交易？

A:
```bash
# 停止后台进程
pkill -f "main.py --realtime-monitor"

# 或者在运行终端按 Ctrl+C
```

---

### Q: 系统会错过交易机会吗？

A: 系统每15分钟检查一次，可能会错过瞬时机会。但这种频率对于短线策略已经足够。

---

### Q: 如何调整策略参数？

A: 编辑 `config.json` 文件，修改 `strategy` 部分的参数：

```json
{
  "strategy": {
    "buy_drop_threshold": 1.0,    // 买入跌幅阈值
    "sell_profit_threshold": 10.0, // 止盈阈值
    "sell_loss_threshold": 5.0,   // 止损阈值
    "max_holding_days": 12        // 最大持仓天数
  }
}
```
