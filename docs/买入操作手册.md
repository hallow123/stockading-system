# 同花顺自动买入操作手册

## 核心要点（必须遵守）

### 1. 日志输出必须加 flush=True
```python
print("步骤1: xxx...", flush=True)
```
不加flush=Python日志会缓冲，看起来像卡住。

### 2. 随机延迟导致"假卡住"
- 每次操作后 `time.sleep(random.uniform(1, 3))` 会等待1-3秒
- 连续5-6次操作 = 5-18秒等待
- **这不是卡住，是正常等待**

### 3. 成功执行流程
```
步骤1: 进入交易界面 → 双击交易按钮(29,422)
步骤2: 选择买入方向 → 点击买入(346,124)
步骤3: 输入股票代码 → 点击代码框(357,183) → 输入601166
步骤4: 输入价格 → 点击价格框(341,233) → 输入18.49
步骤5: 输入数量 → 点击数量框(338,291) → 输入1000
步骤6: 点击确认 → 点击确认按钮(367,340)
步骤7: 最终确认 → 点击最终确认(906,628)
```

### 5. 关键代码模板
```python
import time
import random

def execute_buy_manual():
    """带实时日志的买入执行"""
    
    print("步骤1: 进入交易界面...", flush=True)
    exec_cmd("cliclick c:29,422")  # 双击交易按钮
    time.sleep(random.uniform(1, 3))
    
    print("步骤2: 选择买入方向...", flush=True)
    exec_cmd("cliclick c:346,124")
    time.sleep(random.uniform(1, 3))
    
    print("步骤3: 输入股票代码...", flush=True)
    exec_cmd("cliclick c:357,183")
    time.sleep(0.5)
    exec_cmd("cliclick t:601166")
    time.sleep(random.uniform(1, 3))
    
    print("步骤4: 输入价格...", flush=True)
    exec_cmd("cliclick c:341,233")
    time.sleep(0.5)
    exec_cmd("cliclick t:18.49")
    time.sleep(random.uniform(1, 3))
    
    print("步骤5: 输入数量...", flush=True)
    exec_cmd("cliclick c:338,291")
    time.sleep(0.5)
    exec_cmd("cliclick t:1000")
    time.sleep(random.uniform(1, 3))
    
    print("步骤6: 点击确认...", flush=True)
    exec_cmd("cliclick c:367,340")
    time.sleep(0.5)
    
    print("步骤7: 最终确认...", flush=True)
    exec_cmd("cliclick c:906,628")
    
    print("✅ 买入完成!", flush=True)
```

### 6. 调试技巧

**Q: 怎么看是否真的卡住了？**
A: 看进程是否还在运行，或者检查同花顺界面是否有反应

**Q: 为什么输入没反应？**
A: 先点击输入框，再输入文本（cliclick c: 之后加 ticlick t:）

**Q: 如何快速测试？**
A: 只执行前3步，看股票代码是否正确输入到同花顺
