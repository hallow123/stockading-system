## 一、系统概述

本系统是一个**半自动化的股票交易系统**，通过Python脚本实现以下功能：

1. **实时价格监控** - 每15分钟获取自选股价格
2. **技术指标分析** - MA、MACD、KDJ、RSI等
3. **交易信号生成** - 买入/卖出信号判断
4. **自动交易执行** - 通过同花顺客户端自动下单
5. **风险控制** - 仓位管理、止损止盈、T+1检查
6. **飞书通知** - 实时推送交易信号和报告

## 三、核心模块详解

### 3.1 main.py - 主程序

**功能**: 协调各模块完成每日任务

**主要方法**:

| 方法 | 功能 |
|------|------|
| `daily_task()` | 每日收盘后执行：获取价格→分析→生成报告→发送通知 |
| `realtime_monitor(interval)` | 实时监控（默认15分钟间隔） |
| `execute_trade(trade_signal)` | 执行交易信号 |
| `show_status()` | 显示系统状态 |

**启动命令**:
```bash
# 实时监控模式
python3 main.py -r 15

# 每日报告模式
python3 main.py -d

# 查询单只股票
python3 main.py --fetch --code=002339
```

**执行流程**:
```
1. 加载自选股列表 (stocks.json)
2. 获取实时价格 (price_fetcher.py)
3. 获取历史数据计算MA (trend_analyzer.py)
4. 检查买入/卖出信号
5. 执行交易 (trade_executor.py)
6. 更新持仓 (risk_controller.py)
7. 发送飞书通知 (notification.py)
```

### 3.3 trend_analyzer.py - 趋势分析模块

**技术指标计算**:

| 指标 | 方法 | 说明 |
|------|------|------|
| MA均线 | `calculate_ma(prices, period)` | 5/10/20日均线 |
| EMA | `calculate_ema(prices, period)` | 指数移动平均 |
| MACD | `calculate_macd(prices)` | DIF/DEA/MACD柱 |
| KDJ | `calculate_kdj(prices)` | K/D/J值 |
| RSI | `calculate_rsi(prices, period)` | 相对强弱指标 |

**买入信号判断** (`check_buy_signal`):

```python
# 条件1: MA5 > MA10 > MA20 (均线多头排列) - 置信度+30%
# 条件2: 当日跌幅 > 1% (安全边际) - 置信度+20%
# 条件3: 收盘价 > MA5 (趋势未破) - 置信度+20%
# 条件4: 换手率 >= 2% - 置信度+15%
# 条件5: 振幅 >= 3% - 置信度+15%

# 买入信号: 满足>=2个条件 且 置信度>=40%
```

**卖出信号判断** (`check_sell_signal`):

```python
# 止盈止损:
# - 涨幅达到10%止盈线
# - 跌幅达到5%止损线

# 均线指标:
# - 跌破MA5
# - MA5下穿MA10 (死叉)

# MACD指标:
# - DIF下穿DEA (死叉)

# KDJ指标:
# - J值>80 (超买)
# - K值下穿D值 (死叉)

# RSI指标:
# - RSI>70 (超买)

# 强制平仓:
# - 持有超过12天
```

### 3.5 risk_controller.py - 风险控制模块

**风控配置** (config.json):
```json
{
    "max_position_ratio": 0.8,     // 最大仓位80%
    "stop_loss_ratio": 0.01,       // 止损线1%
    "take_profit_ratio": 0.02,      // 止盈线2%
    "max_holding_days": 2           // 最大持仓天数
}
```

**核心检查** (`should_trade`):

```python
def should_trade(trade_type, stock_code, price, quantity) -> tuple:
    """
    综合判断是否允许交易
    返回: (是否允许, 消息列表)
    """
    
    # 1. 检查是否交易时间 (9:30-11:30, 13:00-15:00)
    # 2. 检查总仓位 (不能超过80%)
    # 3. 检查单只仓位 (买入时)
    # 4. 检查是否持仓 (卖出时)
    # 5. T+1检查: 当日买入，次日才能卖出
    # 6. 止损止盈检查
```

**T+1规则**:
```python
# 买入当天不能卖出
position = positions[stock_code]
buy_date = position.get('buy_date', '')
today = datetime.now().strftime('%Y-%m-%d')

if buy_date == today:
    return False, "T+1规则：今天买入，不能卖出"
```

### 3.6 multi_factor_selector.py - 多因子选股模块

**评分因子** (超短线策略):
```
A. 换手率 (25%) - 越高越好，10%以上标配
B. 成交额 (20%) - 越高越好，1亿以上
C. 价格 (15%) - 10元以下最佳
D. 涨跌幅 (40%) - 3%~8%最佳
```

**选股流程**:
```python
1. 获取全市场实时数据 (minishare)
2. 计算综合评分
3. 排除: ST股、创业板、科创板、北交所
4. 按评分排序，取Top N
5. 保存到观察列表 (stocks.json)
```

**执行时间**: 每日18:00 (收盘后)

## 五、潜在风险分析

### 🔴 高风险

| 风险项 | 描述 | 严重程度 | 建议 |
|--------|------|----------|------|
| **自动交易风险** | 代码执行可能出错，导致错误买入/卖出 | ⭐⭐⭐⭐⭐ | 始终使用`auto_confirm=False`，人工确认 |
| **价格获取失败** | minishare服务不可用时无法交易 | ⭐⭐⭐⭐ | 保留备用数据源或人工干预 |
| **同花顺界面变更** | 客户端UI更新会导致坐标失效 | ⭐⭐⭐⭐ | 定期验证坐标，必要时更新 |
| **网络延迟** | 网络问题导致下单延迟或失败 | ⭐⭐⭐ | 增加重试机制和超时处理 |
| **T+1规则违反** | 代码bug可能导致当天买当天卖 | ⭐⭐⭐⭐⭐ | 严格检查buy_date |

### 🟠 中风险

| 风险项 | 描述 | 严重程度 | 建议 |
|--------|------|----------|------|
| **持仓同步** | positions.json与实际持仓不同步 | ⭐⭐⭐ | 定期手动核对 |
| **重复买入** | 信号重复触发导致多次买入 | ⭐⭐⭐ | 添加买入冷却期 |
| **止盈止损滑点** | 实际成交价与信号价有差异 | ⭐⭐ | 适当放宽止盈止损阈值 |
| **行情数据延迟** | 实时数据可能有秒级延迟 | ⭐⭐ | 结合多个数据源验证 |

### 🟡 低风险

| 风险项 | 描述 | 严重程度 | 建议 |
|--------|------|----------|------|
| **Excel文件锁定** | 多人同时编辑导致冲突 | ⭐ | 添加文件锁或备份 |
| **日志文件过大** | 长时间运行日志堆积 | ⭐ | 定期清理或轮转 |
| **Token过期** | minishare Token失效 | ⭐⭐ | 定期检查更新 |

## 六、风险缓解措施

### 6.1 交易前检查
```python
# 1. 检查是否交易时间
if not is_trading_hours():
    return False

# 2. 检查T+1规则
if buy_date == today:
    return False

# 3. 检查止损止盈
if profit_ratio <= -stop_loss_ratio:
    return False
```

### 6.2 交易后确认
```python
# 发送飞书通知确认
send_trade_result(result)

# 记录完整交易日志
save_trades(trades)
```

### 6.3 异常处理
```python
try:
    # 执行交易
    result = execute_buy(...)
except Exception as e:
    # 记录错误
    logger.error(f"交易失败: {e}")
    # 发送告警
    send_alert(f"交易异常: {e}")
```
